Overview

Mason copies the tables you add from your Postgres, keeps them current, and answers analytics SQL at a Postgres URL of its own. Here: whether the copy is ready, how to connect, and what it answered — what mason status says.

Asking Mason…

Tables

The database's tables, as mason tables lists them. Add one and Mason copies it: it is added to the sources file, as mason add does; Remove takes it out and drops its copy, as mason remove does.

Queries

The statements the Postgres API answers: who is connected, what runs now, the SQL it refused as unsupported, and every statement that ran, as mason status and mason logs list them.

The statements answered, refused or cancelled, as mason logs --requests lists them, newest first, over the time range above. Since, when given, is used instead: an age (30m, 2h, 7d) or an ISO 8601 date or time with its zone. A statement that reads no copied table (select 1, SET, SHOW, a BI tool's catalog queries) is answered but not listed.

Users

A user is the name and password psql, a BI tool or your app connects to Mason with; it does not expire. The same users as mason user.
