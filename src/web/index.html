Overview

What mason status says: whether the copy is ready, the database, the sync and the statements.

Asking Mason…

Tables

The database's tables, as mason tables lists them. Add one and Mason copies it: it is added to the sources file, as mason add does; Remove takes it out and drops its copy, as mason remove does.

Queries

The statements the Postgres API answers: who is connected, what runs now, and every statement that ran, as mason logs lists them.

Running now

Request log

The statements answered, refused or cancelled, as mason logs --requests lists them, newest first, over the time range above. Since, when given, is used instead: an age (30m, 2h, 7d) or an ISO 8601 date or time with its zone.

Users

A user of the Postgres API: a name and a password that does not expire, for a BI tool or an app. The same users as mason user.

Usage

What the Postgres API answered over the time range and each copy's size, as mason usage prints them.
