Status

What mason status says: whether the copy is ready, the database, the sync and the statements.

Asking Mason…

Tables

The database's tables, as mason tables lists them. Add one and Mason copies it: it is added to the sources file, as mason add does; Remove takes it out and drops its copy, as mason remove does.

Queries

Connected now

The clients with a session open: a row per user and client.

Running now

The statements running now, as mason logs --running lists them. Cancel stops one, as mason cancel does.

Request log

The statements the Postgres API answered, refused or cancelled, as mason logs --requests lists them. Since is an age (30m, 2h, 7d) or an ISO 8601 date or time with its zone.

Users

A user of the Postgres API: a name and a password that does not expire, for a BI tool or an app. The same users as mason user.
